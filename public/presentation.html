AI가 잘하는 것 vs 사람이 해야 하는 것

AI가 잘하는 것

  • 정보 구조(IA)와 화면 흐름
  • 일관된 스펙 체계 (간격, 사이즈)
  • 접근성 가이드라인 기반 설계
  • 빠른 시안 생성 (수분 내)

사람이 꼭 해야 하는 것

  • 브랜드 톤앤매너 감성 판단
  • 타겟의 문화·맥락 이해
  • 위험 동작 UX 안전장치
  • "이게 정말 편한가?" 체감 판단
